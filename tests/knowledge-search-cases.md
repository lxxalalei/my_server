## 人工评测记录

每条记录：`通过/失败/无法测试`，同时记录四项：
1. **检索真实性**：是否真正使用可用工具读取知识。
2. **事实准确性**：回答是否与读取文档一致。
3. **适用性**：是否区分演示/正式、终端、版本和角色。
4. **交互连续性**：是否利用既有上下文；信息不足时是否合理处理。

任何情况下，如果环境没有 GitHub 访问工具，不能把 KS-01～KS-10 判定为“已验证检索通过”。应标记“无法测试”并记录缺少的能力。
